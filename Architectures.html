Evolusi Model

Arsitektur Populer CNN

Perkembangan model-model CNN bersejarah yang mendorong revolusi Computer Vision.

1998

LeNet-5

Dikembangkan oleh Yann LeCun dan rekan-rekannya. Tujuan awalnya adalah mengenali digit tulisan tangan (dataset MNIST), misalnya untuk membaca angka pada cek bank dan kode pos. LeNet-5 adalah CNN modern pertama yang terbukti berhasil di dunia nyata.

  • Input citra grayscale 32×32 piksel
  • 2 Convolution + 2 Average Pooling
  • 3 Fully Connected Layer di bagian akhir
  • Aktivasi tanh/sigmoid
7 layer ±60 ribu parameter
2012

AlexNet

Karya Alex Krizhevsky, Ilya Sutskever, dan Geoffrey Hinton. AlexNet memenangkan ImageNet (ILSVRC) 2012 dengan selisih error yang sangat besar dibanding metode non-deep-learning, dan menjadi titik awal ledakan deep learning di Computer Vision.

  • ReLU menggantikan tanh, pelatihan jauh lebih cepat
  • Dropout untuk mengurangi overfitting
  • Dilatih menggunakan GPU
  • Data augmentation pada citra latih
8 layer (5 Conv + 3 FC) ±60 juta parameter
2014

VGG-16

Dikembangkan oleh Visual Geometry Group, Universitas Oxford. Idenya sederhana: tumpuk banyak filter kecil 3×3 secara berulang. Dua filter 3×3 berurutan punya jangkauan pandang yang sama dengan satu filter 5×5, tetapi parameternya lebih sedikit dan non-linearitasnya lebih banyak.

  • Hanya memakai Conv 3×3 dan MaxPool 2×2
  • Struktur seragam, mudah dipahami
  • Populer untuk transfer learning
16 layer (13 Conv + 3 FC) ±138 juta parameter
2015

ResNet (Residual Network)

Dikembangkan oleh Kaiming He dkk. dari Microsoft Research dan memenangkan ImageNet 2015. Semakin dalam sebuah jaringan, semakin sulit dilatih karena gradien menghilang (vanishing gradient) dan akurasi justru menurun. ResNet mengatasinya dengan Skip Connection: input sebuah blok dijumlahkan langsung ke outputnya, sehingga blok hanya perlu mempelajari selisih (residual) dan gradien punya jalur pintas saat backpropagation.

Output = F(x) + x
  • Memungkinkan jaringan hingga 152 layer atau lebih
  • Varian umum: ResNet-18, 34, 50, 101, 152
ResNet-50: 50 layer ±25 juta parameter
2017

MobileNet

Dikembangkan oleh tim Google untuk perangkat dengan sumber daya terbatas seperti smartphone dan perangkat edge. Kuncinya adalah Depthwise Separable Convolution, yaitu konvolusi standar dipecah menjadi dua tahap: depthwise (satu filter per channel) lalu pointwise (konvolusi 1×1 untuk menggabungkan channel). Hasilnya komputasi turun sekitar 8–9 kali dengan penurunan akurasi yang kecil.

Depthwise 3×3 → Pointwise 1×1
  • Parameter width multiplier dan resolution multiplier untuk mengatur ukuran model
  • Cocok untuk inferensi real-time di perangkat mobile
28 layer (MobileNetV1) ±4 juta parameter
