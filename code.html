Implementasi Praktis

Membangun Model CNN dengan Python

Contoh implementasi arsitektur Convolutional Neural Network sederhana menggunakan TensorFlow / Keras untuk klasifikasi citra 10 kelas (dataset CIFAR-10).

cnn_cifar10.py 
import tensorflow as tf
from tensorflow.keras import datasets, layers, models

# 1. Memuat & Normalisasi Dataset (Nilai piksel 0-255 menjadi 0-1)
(train_images, train_labels), (test_images, test_labels) = datasets.cifar10.load_data()
train_images, test_images = train_images / 255.0, test_images / 255.0

# 2. Membangun Arsitektur Model CNN Sequential
model = models.Sequential([
    # Blok Konvolusi 1: Ekstraksi fitur dasar (tepi & warna)
    layers.Conv2D(32, (3, 3), activation='relu', input_shape=(32, 32, 3)),
    layers.MaxPooling2D((2, 2)),

    # Blok Konvolusi 2: Ekstraksi pola lebih kompleks
    layers.Conv2D(64, (3, 3), activation='relu'),
    layers.MaxPooling2D((2, 2)),

    # Blok Konvolusi 3
    layers.Conv2D(64, (3, 3), activation='relu'),

    # Bagian Klasifikasi (Fully Connected)
    layers.Flatten(),
    layers.Dense(64, activation='relu'),
    layers.Dense(10, activation='softmax')
])

# 3. Kompilasi Model
model.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)

# 4. Pelatihan Model (Training)
history = model.fit(
    train_images, train_labels,
    epochs=10,
    validation_data=(test_images, test_labels)
)
Bedah Struktur Layer
  • Normalisasi (/ 255.0)

    Mengubah rentang nilai intensitas piksel RGB dari 0–255 menjadi skala 0–1 agar proses konvergensi gradien lebih cepat dan stabil.

  • Conv2D(32, (3, 3), activation='relu')

    Menerapkan 32 kernel berukuran 3×3 pada gambar input berdimensi 32×32×3 (RGB), diikuti aktivasi ReLU untuk menghilangkan nilai negatif.

  • MaxPooling2D((2, 2))

    Mengambil nilai maksimum dari setiap area 2×2 piksel, sehingga ukuran feature map menyusut setengahnya dan komputasi jauh lebih ringan.

  • Flatten()

    Meratakan matriks feature map 3D hasil ekstraksi fitur menjadi vektor 1 dimensi agar dapat diproses oleh jaringan Dense klasik.

  • Dense(10, activation='softmax')

    Output layer dengan 10 neuron sesuai jumlah kelas CIFAR-10. Fungsi Softmax mengubah skor akhir menjadi probabilitas dengan total 100%.

1
Siapkan Environment

Buka Google Colab atau Jupyter Notebook. Pastikan library tensorflow sudah terpasang (di Google Colab sudah tersedia secara bawaan).

2
Aktifkan Akselerasi GPU

Pada Google Colab, pilih menu Runtime → Change runtime type → T4 GPU agar proses pelatihan 10 epoch selesai dalam hitungan detik.

3
Evaluasi Akurasi

Bandingkan nilai accuracy (data latih) dengan val_accuracy (data uji). Jika selisihnya terlalu jauh, tambahkan layer Dropout(0.2).
