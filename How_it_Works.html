CNN Architecture

How Convolutional Neural Networks Work

A Convolutional Neural Network (CNN) processes images by extracting important visual features and using them to identify and classify objects automatically.

The CNN Processing Flow

Six main stages transform an image into a classification result.

Input Image
Convolution
ReLU
Pooling
Flattening
Fully Connected & Softmax

Understanding the Six Stages

Learn what happens at each stage of CNN image processing.

01

Input Image

The process begins when an image is provided to the CNN. A computer represents an image as numerical pixel values arranged in a matrix.

A grayscale image normally has one channel, while an RGB image has three channels: Red, Green, and Blue. Before processing, pixel values may be normalized to make computation more consistent.

Example: An RGB image with dimensions 64 × 64 has a data shape of 64 × 64 × 3.
02

Convolution Layer

The convolution layer uses small matrices called kernels or filters to scan the input image. Each filter moves across the image and performs multiplication and addition operations with the pixel values.

The movement distance is controlled by a parameter called stride. The results form feature maps that highlight patterns such as edges, lines, and textures.

Example: A 3 × 3 filter moves across an image to detect important visual patterns.
03

Activation Function (ReLU)

After convolution, the ReLU activation function is applied to the feature maps. It replaces negative values with zero while keeping positive values unchanged.

ReLU introduces non-linearity, allowing the CNN to learn more complex patterns rather than only simple linear relationships.

f(x) = max(0, x)
Example: If the input is -5, ReLU returns 0. If the input is 8, ReLU returns 8.
04

Pooling Layer

Pooling reduces the spatial dimensions of feature maps while keeping important information. This helps reduce computation and the amount of data passed to later layers.

Two common methods are Max Pooling, which selects the largest value in a region, and Average Pooling, which calculates the average value.

Example: A 2 × 2 Max Pooling operation selects the highest value from each 2 × 2 region.
05

Flattening

After convolution, activation, and pooling, the extracted feature maps are converted into a one-dimensional vector.

This operation is called flattening. It prepares the extracted visual information so it can be passed into the fully connected layer for classification.

Example: A feature map with dimensions 4 × 4 × 2 becomes a one-dimensional vector containing 32 values.
06

Fully Connected & Softmax

The flattened vector is passed to the fully connected layer. Here, neurons combine the extracted features to determine which class the image most likely belongs to.

The final classification layer can use Softmax to convert its output scores into probabilities for each class. The class with the highest probability becomes the predicted result.

Example: A model may predict 90% probability for a cat and 10% for a dog. The predicted class is cat.

From Pixels to Predictions

A CNN works by gradually extracting visual features from an image and transforming them into useful information for classification. Each stage has an important role in helping the model recognize objects and patterns automatically.
